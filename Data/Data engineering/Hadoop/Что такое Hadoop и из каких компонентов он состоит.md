### **Что такое Hadoop?**

**Hadoop** — это фреймворк с открытым исходным кодом для распределённой обработки и хранения больших данных (Big Data) на кластерах из обычных серверов. Он основан на модели MapReduce и файловой системе HDFS (Hadoop Distributed File System).

### **Основные компоненты Hadoop**

1. **HDFS (Hadoop Distributed File System)**
    
    - Распределённая файловая система, обеспечивающая хранение данных на множестве узлов.
        
    - Состоит из:
        
        - **NameNode** (главный узел, управляет метаданными)
            
        - **DataNode** (узлы хранения данных)
            
2. **YARN (Yet Another Resource Negotiator)**
    
    - Управляет ресурсами кластера и планированием задач.
        
    - Позволяет запускать различные обработчики данных (не только MapReduce).
        
3. **MapReduce**
    
    - Вычислительная модель для параллельной обработки больших данных.
        
    - Состоит из двух этапов:
        
        - **Map** (фильтрация и сортировка данных)
            
        - **Reduce** (агрегация результатов)
