Если стоят контейнеры в работе, максимальный снов это следующий алгоритм


### 1. Остановите ВСЕ контейнеры (даже вне текущего проекта)
docker stop $(docker ps -q)

### 2. Удалите все остановленные контейнеры
docker container prune -f

### 3. Удалите все неиспользуемые сети
docker network prune -f

### 4. Удалите volumes (если нужен полный сброс)
docker volume prune -f

### 5. Проверьте, что сеть освободилась
docker network ls


**После очистки выполнил следующее**
### В каталоге проекта:
docker-compose down -v
docker-compose up -d

### Проверьте, что контейнеры стартовали и НЕ перезапускаются
docker-compose ps
