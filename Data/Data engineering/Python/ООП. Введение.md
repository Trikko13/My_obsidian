Пример кода с сайта

`class Cat():`
  `def __init__(self, breed, color, age):`
     `self.breed = breed`
     `self.color = color`
     `self.age = age`

  `def meow(self):`
     `print('Мяу!')`

  `def purr(self):`
     `print('Мрррр')`

Здесь __init__ инициализирует класс и вызывается после создания объекта для присваивания  динамик. атрибутов, 
__self__  тут сложит как ссылка  на текущий объект ,она дает доступ к методам и аттрибутам объекта
