## Какие есть в питоне структуры данных по умолчанию?

В Python есть четыре основные структуры данных по умолчанию: `list`, `tuple`, `dict`, `set`. Кроме того, доступны `frozenset` и `collections` структуры, такие как `deque`.[corporatefinanceinstitute+3](https://corporatefinanceinstitute.com/resources/data-science/python-data-structures/)​

## Какую структуру выберу в каких случаях, если пишу код, в котором надо обращаться к элементам?

- `list` — для упорядоченных изменяемых коллекций, когда важно индексное обращение. O(1) — доступ по индексу.[educative](https://www.educative.io/blog/8-common-data-structures-in-python-every-programmer-must-know)​
    
- `tuple` — для неизменяемых коллекций, если требуется хэширование или фиксированный набор элементов.[educative](https://www.educative.io/blog/8-common-data-structures-in-python-every-programmer-must-know)​
    
- `dict` — для быстрого доступа к данным по ключу, O(1) — вставка, поиск, удаление.[educative](https://www.educative.io/blog/8-common-data-structures-in-python-every-programmer-must-know)​
    
- `set` — для хранения уникальных элементов и быстрой проверки принадлежности.[educative](https://www.educative.io/blog/8-common-data-structures-in-python-every-programmer-must-know)​
    

## Что такое Linked List? Чем отличается от массива?

- **Linked List** — коллекция узлов, где каждый узел хранит данные и ссылку на следующий узел. Добавление/удаление элементов — O(1), доступ по индексу — O(n).[w3schools+1](https://www.w3schools.com/python/python_dsa_linkedlists.asp)​
    
- **Массив** — структура хранения данных в непрерывной области памяти. Быстрый доступ по индексу — O(1), но добавление/удаление в начале — O(n).[stackoverflow+2](https://stackoverflow.com/questions/914233/what-is-the-underlying-data-structure-for-python-lists)​
    

## Есть парсер, который ходит на одну из проксей из набора. Какую структуру выбрать, чтобы максимально сбалансировать нагрузку по обращениям к ним?

Для балансировки нагрузки можно использовать `deque` из `collections` или обычный список с циклическим индексом. Это позволяет распределить нагрузку равномерно, используя алгоритм «round-robin».[educative](https://www.educative.io/blog/8-common-data-structures-in-python-every-programmer-must-know)​

## Как работает garbage collector в питоне?

Python использует два механизма:

- Счётчики ссылок: автоматически удаляет объекты, когда на них не осталось ссылок.[stackify+2](https://stackify.com/python-garbage-collection/)​
    
- Генерационный сборщик: организует объекты по трём поколениям, периодически чистит мусор и разбирается с циклическими ссылками.[python+2](https://docs.python.org/3/library/gc.html)​

## Как отличается классический DWH от Lakehouse?

- DWH: фиксированная схема, структурированные данные, инструменты для аналитики (например, PostgreSQL, Redshift).
    
- Lakehouse: гибкая схема, поддержка структурированных и неструктурированных данных, возможности ML (например, Delta Lake, Iceberg).[educative](https://www.educative.io/blog/8-common-data-structures-in-python-every-programmer-must-know)​
