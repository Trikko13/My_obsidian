Вот основная информация о копировании и ссылочности в Python, а также таблица для быстрого запоминания.

## Основные понятия

- **Присваивание (`=`)**: создает новую ссылку на тот же объект, а не копию. Изменения через одну переменную затронут другую.[digitology](https://digitology.tech/docs/python_3/library/copy.html)​
    
- **Поверхностная копия (`copy.copy()`)**: создает новый объект, но вложенные объекты остаются теми же (ссылки на них копируются).[pythonworld+1](https://pythonworld.ru/moduli/modul-copy.html)​
    
- **Глубокая копия (`copy.deepcopy()`)**: создает полностью независимую копию, включая все вложенные объекты.[sky+1](https://sky.pro/wiki/javascript/deep-copy-v-python-kak-rabotaet-primery-i-alternativy/)​
    

## Таблица: копирование и ссылочность

|Операция|Что делает|Пример для списка с вложенным списком|Изменения в копии влияют на оригинал?|
|---|---|---|---|
|`=` (присваивание)|Создает новую ссылку на тот же объект|`b = a`|Да|
|`copy.copy()`|Создает новый объект, но вложенные объекты — те же (ссылки копируются)|`b = copy.copy(a)`|Да, если изменяются вложенные объекты|
|`copy.deepcopy()`|Создает полностью независимую копию, включая все вложенные объекты|`b = copy.deepcopy(a)`|Нет|

## Дополнительные нюансы

- Для простых типов (числа, строки) разницы между `copy` и `deepcopy` нет, так как они не содержат вложенных объектов.[w3docs](https://ru.w3docs.com/quiz/question/AGDlAj==)​
    
- Для сложных объектов (списки списков, словари со списками и т.д.) важно использовать `deepcopy`, если нужно полностью независимую копию.[sky+1](https://sky.pro/wiki/javascript/shallow-i-deep-copy-v-python-raznica-i-kogda-ispolzovat/)​
    
- Классы могут переопределять поведение копирования через методы `__copy__()` и `__deepcopy__()`.[pythonworld](https://pythonworld.ru/moduli/modul-copy.html)​
    

## Примеры

python

`import copy # Пример с вложенным списком original = [[1, 2], [3, 4]] # Присваивание assigned = original assigned[0][0] = 'X' print(original)  # [[X, 2], [3, 4]] # Поверхностная копия shallow = copy.copy(original) shallow[0][0] = 'Y' print(original)  # [[Y, 2], [3, 4]] # Глубокая копия deep = copy.deepcopy(original) deep[0][0] = 'Z' print(original)  # [[Y, 2], [3, 4]]`

## Советы

- Используйте `copy.copy()` для простых объектов или когда не нужно копировать вложенные структуры.
    
- Используйте `copy.deepcopy()` для сложных объектов, если нужна полная независимость.
    
- Для примитивных типов (int, str, float) копирование не требуется — они всегда копируются по значению.[w3docs](https://ru.w3docs.com/quiz/question/AGDlAj==)​
