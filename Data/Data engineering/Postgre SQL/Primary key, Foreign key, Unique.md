Вот таблица, в которой представлены основные особенности и применения **Primary Key**, **Foreign Key** и **Unique Key** в PostgreSQL:

| **Ключ**       | **Описание**                                                              | **Условия**                                   | **Применение**                                               | **Индексация**                | **Допустимые NULL** | **Количество**                              |
|----------------|---------------------------------------------------------------------------|-----------------------------------------------|------------------------------------------------------------|-------------------------------|---------------------|---------------------------------------------|
| **Primary Key** | Уникальный идентификатор для каждой записи в таблице.                    | Должен быть уникальным и не может быть NULL. | Определяет основное поле для идентификации каждой записи.   | Автоматически создается индекс. | Нет                 | Один для каждой таблицы                    |
| **Foreign Key**  | Связывает одну таблицу с другой, создавая связь между ними.           | Ссылается на Primary Key другой таблицы.     | Обеспечивает целостность данных, предотвращая недопустимые ссылки. | Может быть проиндексирован.    | Да                  | Несколько в одной таблице                  |
| **Unique Key**   | Гарантирует, что значения в столбце уникальны, но может содержать NULL. | Не может иметь дублирующихся значений.       | Применяется для столбцов, где нужно обеспечить уникальность (например, email). | Автоматически создается индекс. | Да (в одном экземпляре) | Несколько для одной таблицы               |

---

### Краткие пояснения

- **Primary Key**: Используется для уникальной идентификации записей в таблице. Не может содержать NULL Значения.
  
- **Foreign Key**: Создает связь между таблицами, ссылаясь на Primary Key другой таблицы. Это помогает поддерживать целостность базы данных.

- **Unique Key**: Обеспечивает уникальность значений в столбце, но допускает наличие значений NULL, что делает его полезным для некоторых полей, таких как адреса электронной почты.
