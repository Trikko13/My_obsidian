# Четыре критерия правильной задачи (по Дорофееву)

## 💡 Суть идеи

Задача, сформулированная "на бегу" без размышлений, — это ловушка. Правильная задача должна соответствовать **четырём критериям**, иначе обезьянка (лимбическая система) будет прокрастинировать.

---

## 🎯 Четыре критерия

### 1. Отвечает на вопрос "что нужно сделать?"

**Плохо:**
- "Подумать над проектом X"
- "Разобраться с крипто-портфелем"
- "Изучить токеномику"

**Хорошо:**
- "Написать первый абзац статьи про проект X"
- "Открыть Excel, выписать все позиции портфеля"
- "Прочитать tokenomics раздел в whitepaper Celestia"

### 2. Формулировка начинается с глагола в неопределённой форме

**Глаголы действия:**
- Позвонить, написать, купить, продать, открыть, создать, отправить

**Плохо:**
- "Проект по ресерчу DeFi" (существительное)
- "Анализ токеномики Celestia" (существительное)

**Хорошо:**
- "Начать проект: создать файл в Obsidian"
- "Проанализировать токеномику: выписать распределение токенов"

### 3. Исполнение требует минимум мыслетоплива

**Правило:** "Проще было сделать, чем писать!"

**Плохо (много мыслетоплива):**
- "Разработать стратегию инвестирования в DeFi"
  - Обезьянка: "Ааа, надо думать, сложно, потом!"
  
**Хорошо (мало мыслетоплива):**
- "Открыть CoinGecko, выписать топ-5 DeFi по TVL"
  - Обезьянка: "Ок, легко, сделаю прямо сейчас!"

### 4. Задача — первоочередное действие к цели

**Пример:**
- **Цель:** Составить программу тренировок для спины
- **Плохая задача:** "Составить программу тренировок" (слишком абстрактно)
- **Хорошая задача:** "Собрать 10 упражнений для спины из GPT в один список"
  - Это **первый шаг**, после которого рациональный тип сформулирует следующий

---

## ⏱️ Правило 30 минут

**Дорофеев:**
> "Задача должна выполняться не более 30 минут, иначе обезьянка испугается и начнёт прокрастинировать мелочью."

**Почему 30 минут?**
- Обезьянка видит конец задачи
- Не успевает устать
- Чувство прогресса → дофамин → мотивация

**Если задача >30 минут:**
→ Разбить на под-задачи по 30 минут

## ✅ Мои примеры (применение)

### Крипта

**❌ Плохая задача:**
- "Изучить проект Celestia"

**✅ Хорошая задача:**
- "Прочитать раздел 'How it works' в docs.celestia.org (20 мин)"
- Следующая: "Выписать 3 ключевые особенности в Obsidian (10 мин)"

### Data Engineering

**❌ Плохая задача:**
- "Изучить Window Functions в SQL"

**✅ Хорошая задача:**
- "Открыть курс SQL, посмотреть урок 5 про Window Functions (25 мин)"
- Следующая: "Написать 3 примера запросов с OVER() в DBeaver (15 мин)"

### Здоровье

**❌ Плохая задача:**
- "Начать делать упражнения для спины"

**✅ Хорошая задача:**
- "Найти в YouTube видео 'упражнения для спины 10 минут' (5 мин)"
- Следующая: "Сделать первые 3 упражнения из видео (10 мин)"

## 🧠 Почему это работает

**Психология:**
1. **Ясность** → нет страха неопределённости
2. **Глагол** → действие, не раздумья
3. **Минимум мыслетоплива** → нет перегрузки
4. **Первый шаг** → прогресс виден сразу
5. **30 минут** → видишь конец туннеля

**Результат:** Обезьянка говорит "Ок, давай!" вместо "Потом, сложно, страшно!"
