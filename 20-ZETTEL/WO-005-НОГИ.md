## **8. ЖИМ НОГАМИ**

### **⚠️ КРИТИЧНО для тебя:** вальгус коленей + гиперэкстензия правого

### **ИП:**

```
Тренажёр для жима ногами:
- Угол наклона платформы: 45°
- Постановка стоп: чуть шире плеч
- Носки развёрнуты наружу 10-15° (как у тебя при ходьбе)
- Спина прижата к спинке ПОЛНОСТЬЮ
- Поясница НЕ оторвана
```

**Настройка (ВАЖНО!):**

1. Сесть, прижать спину + поясницу к спинке
2. Поставить стопы на платформу: **ПОЛНОСТЬЮ** (не только носки!)
3. **Колени НАД СТОПАМИ** (проверить сверху!)
4. Руками взяться за ручки (стабилизация)
5. Снять стопоры

### **Фаза опускания:**

```
Секунды:  1  -  2  -  3
Действие: опускать платформу → колени к груди → до 90° → СТОП
```

**Техника (КОНТРОЛЬ КОЛЕНЕЙ!):**

- Опускать **МЕДЛЕННО** (3 сек)
- **КОЛЕНИ НАД СТОПАМИ!** (самое важное! не сводить!)
- Опускать **ДО 90° в коленях** (не глубже! для правого колена!)
- **Правое колено НЕ блокировать!** (всегда микросгибание)
- **Поясница прижата** к спинке (не отрывать!)
- Стопы **НЕ отрываются** от платформы (вес на пятках!)

### **Фаза подъёма:**

```
Секунды:  1  -  2
Действие: выжать платформу → колени НЕ блокировать → контроль
```

**Техника:**

- Выжимать **МОЩНО** (2 сек)
- **Отталкиваться ПЯТКАМИ** (не носками!)
- **КОЛЕНИ НЕ БЛОКИРОВАТЬ!** ← критично для правого! (оставить микросгибание)
- **Колени НАД СТОПАМИ** весь подход!
- Выдох при подъёме

### **❌ Типичные ошибки (ТВОИ ПРОБЛЕМЫ!):**

|**Ошибка**|**Почему опасно для тебя**|**Как исправить**|
|---|---|---|
|**Колени внутрь (вальгус)**|Перерастяжение связок, боль|**РАЗВОДИТЬ КОЛЕНИ!** Думать об этом каждый подход!|
|**Блокировка правого колена**|Гиперэкстензия усиливается|**ОСТАВИТЬ МИКРОСГИБАНИЕ!** Никогда не выпрямлять до упора!|
|Отрыв поясницы|Перегрузка, торсия таза|**ПРИЖАТЬ!** Опускать не глубже 90°|
|Вес на носках|Стопы не работают|**ВЕС НА ПЯТКАХ!** Пальцы можно даже приподнять|

### **💡 Совет для тебя:**

**Первый подход — с ЛЕГКИМ весом (50кг), перед зеркалом (вид сверху):**

- Медленно опускать, смотреть на колени
- Проверять, что **колени НАД стопами** (не сводятся!)
- Отработать паттерн, потом добавлять вес

### **Что должен чувствовать:**

- ✅ Работу **квадрицепсов** (передняя часть бедра)
- ✅ Работу **ягодиц** (при подъёме)
- ✅ Давление в **пятках**
- ❌ НЕ должно болеть в **коленях** или **пояснице**

### **Прогрессия:**

```
Неделя 1-2:  3×15, 100кг (отработка техники!)
Неделя 3-4:  3×15, 120кг
Неделя 5-6:  3×15, 140кг
Неделя 7-12: 3×12-15, 150-170кг
```

## **9. РУМЫНСКАЯ ТЯГА**

### **Цель:** задняя цепь (подколенные + ягодицы) — критично для правого колена!

### **ИП:**

```
Стоя, штанга в руках:
- Хват: на ширине плеч
- Стопы: на ширине таза, параллельно
- Колени СЛЕГКА СОГНУТЫ (10-15°) ← критично!
- Спина прямая, грудь вперёд
- Штанга на уровне бёдер
```

**Подготовка:**

1. Встать, взять штангу
2. **КОЛЕНИ СЛЕГКА СОГНУТЬ** (и НЕ менять угол весь подход!)
3. Лопатки свести
4. **Напрячь ягодицы** (подкрутить таз)

### **Фаза опускания:**

```
Секунды:  1  -  2  -  3  -  4
Действие: наклон от ТАЗА → штанга вдоль ног → до растяжения → СТОП
```

**Техника (ОБУЧЕНИЕ ПРАВИЛЬНОГО ПАТТЕРНА!):**

- **Колени СЛЕГКА СОГНУТЫ весь подход!** (угол НЕ меняется!) ← для правого колена!
- Наклон **ОТ ТАЗА** (таз назад, корпус вперёд)
- **Спина ПРЯМАЯ** (не округлять!)
- Штанга **ВДОЛЬ НОГ** (скользит по ногам)
- Опускать **ДО РАСТЯЖЕНИЯ подколенных** (обычно до середины голени)
- **НЕ опускать до пола!** (это не становая!)
- **Чувствовать растяжение ягодиц + подколенных**

### **Фаза подъёма:**

```
Секунды:  1  -  2  -  3
Действие: выпрямиться → толкнуть таз вперёд → сжать ягодицы → СТОП
```

**Техника:**

- Подниматься **СИЛОЙ ЯГОДИЦ** (не поясницы!)
- **Толкнуть таз вперёд** (как в ягодичном мостике)
- **Сжать ягодицы вверху** (пауза 1 сек)
- **Колени остаются слегка согнутыми!** (НЕ выпрямлять!)
- Лопатки сведены

### **❌ Типичные ошибки:**

|**Ошибка**|**Почему опасно для тебя**|**Как исправить**|
|---|---|---|
|**Выпрямление коленей**|Гиперэкстензия правого колена!|**ДЕРЖАТЬ СОГНУТЫМИ!** Весь подход!|
|Округление спины|Перегрузка поясницы|**ГРУДЬ ВПЕРЁД!** Свести лопатки|
|Приседание|Не работают подколенные|**НАКЛОН от ТАЗА!** Колени НЕ уходят вперёд|
|Подъём спиной|Перегрузка поясницы|**ТОЛКАТЬ ТАЗОМ!** Думать о ягодицах|

### **Что должен чувствовать:**

- ✅ **РАСТЯЖЕНИЕ подколенных** (сзади бедра) при опускании
- ✅ **Работу ягодиц** при подъёме
- ✅ Напряжение в **пояснице** (держит спину, но НЕ болит!)
- ❌ НЕ должно болеть в **коленях** или **сильно в пояснице**

### **💡 Для тебя (правое колено):**

**Румынская тяга — ЛУЧШЕЕ упражнение для укрепления подколенных!**

- Сильные подколенные = защита от гиперэкстензии
- Делай **МЕДЛЕННЫЙ негатив** (4-5 сек опускание)
- Фокус на **растяжении + контроле**

### **Прогрессия:**

```
Неделя 1-2:  3×10, 30кг (отработка техники! гриф 20кг + 2×5кг)
Неделя 3-4:  3×10, 40кг
Неделя 5-6:  3×10, 50кг
Неделя 7-12: 3×10-12, 60-70кг
```

## **10. БОЛГАРСКИЕ ПРИСЕДАНИЯ**

### **Цель:** выравнивание асимметрии (у тебя 45%/55%) + контроль вальгуса

### **ИП:**

```
Одна нога на скамье сзади, другая впереди:
- Задняя нога: носок на скамье (высота 40-50см)
- Передняя нога: на полу, стопа ПОЛНОСТЬЮ
- Расстояние: 60-80см (подобрать индивидуально)
- Корпус вертикально
- Гантели в руках вдоль тела ИЛИ одна у груди
```

**Подготовка:**

1. Поставить заднюю ногу на скамью
2. Проверить расстояние: при опускании **колено НЕ выходит за носок**
3. **Вес на передней ноге** (задняя — только для баланса!)
4. Грудь вперёд

### **Фаза опускания:**

```
Секунды:  1  -  2  -  3
Действие: опуститься ВЕРТИКАЛЬНО вниз → колено над стопой → СТОП
```

**Техника (КОНТРОЛЬ В ЗЕРКАЛЕ!):**

- Опускаться **ВЕРТИКАЛЬНО ВНИЗ** (не вперёд!)
- **КОЛЕНО НАД СТОПОЙ!** ← смотри в зеркало сбоку!
- **Колено НЕ уходит внутрь** (вальгус!) ← смотри спереди!
- Опускаться **ДО УГЛА 90°** в переднем колене
- **Вес на ПЯТКЕ** передней ноги (не на носке!)
- Корпус вертикально (слегка наклонён вперёд 5-10°)

### **Фаза подъёма:**

```
Секунды:  1  -  2
Действие: подняться → толкнуть пяткой → НЕ блокировать колено
```

**Техника:**

- **Отталкиваться ПЯТКОЙ** передней ноги
- Подниматься **ВЕРТИКАЛЬНО ВВЕРХ**
- **Колено НАД СТОПОЙ** весь подход!
- **НЕ блокировать колено** вверху (микросгибание)
- Активировать ягодицу при подъёме

### **❌ Типичные ошибки (ТВОИ ПРОБЛЕМЫ!):**

|**Ошибка**|**Почему опасно для тебя**|**Как исправить**|
|---|---|---|
|**Колено внутрь (вальгус)**|Усиливает проблему, боль|**КОНТРОЛЬ В ЗЕРКАЛЕ!** Каждый подход проверять!|
|Колено за носок|Перегрузка, гиперэкстензия|**ВНИЗ, а не вперёд!** Проверить расстояние|
|Вес на носке|Стопа не работает, плоскостопие усиливается|**ВЕС НА ПЯТКЕ!** Можно даже приподнять пальцы|
|Наклон вперёд|Не работают ягодицы|**КОРПУС ВЕРТИКАЛЬНО!** Грудь вверх|

### **💡 Для тебя (асимметрия 45%/55%):**

**ОБЯЗАТЕЛЬНО начинай со СЛАБОЙ (левой) ноги!**

1. 3 подхода левой ногой
2. 3 подхода правой ногой **С ТЕМ ЖЕ ВЕСОМ** (даже если легче!)
3. НЕ увеличивай вес на правой!
4. Цель: выровнять силу → потом прогрессировать

**КОНТРОЛЬ ВАЛЬГУСА:**

- Первый подход — **БЕЗ веса**, перед зеркалом (вид спереди)
- Медленно опускаться, смотреть на колено
- Проверять, что **колено НЕ уходит внутрь**
- Отработать паттерн, потом добавлять вес

### **Что должен чувствовать:**

- ✅ Работу **ягодицы** передней ноги
- ✅ Работу **квадрицепса** (немного)
- ✅ Растяжение **сгибателей бедра** задней ноги
- ❌ НЕ должно болеть в **колене**

### **Прогрессия:**

```
Неделя 1-2:  3×10, без веса (отработка!)
Неделя 3-4:  3×10, 8кг гантели
Неделя 5-6:  3×10, 12кг
Неделя 7-12: 3×10-12, 16кг
```

## **11. СГИБАНИЯ НОГ ЛЁЖА**

### **Цель:** укрепление подколенных (защита правого колена от гиперэкстензии!)

### **ИП:**

```
Лёжа лицом вниз на тренажёре:
- Валик под ахиллами (чуть выше пяток)
- Таз прижат к скамье
- Колени на краю скамьи (или слегка свисают)
- Руками взяться за ручки
```

**Подготовка:**

1. Лечь, подогнать валик
2. **Таз ПРИЖАТЬ к скамье** (не отрывать!)
3. Ноги прямые, носки на себя
4. Напрячь пресс

### **Фаза подъёма:**

```
Секунды:  1  -  2
Действие: согнуть ноги → валик к ягодицам → пауза 1 сек
```

**Техника:**

- Сгибать **МОЩНО** (2 сек)
- **Валик К ЯГОДИЦАМ** (максимальное сгибание)
- **Пауза 1 сек** вверху (сжать подколенные)
- **Таз ПРИЖАТ!** (не отрывать)
- Стопы на себя (дорсифлексия)

### **Фаза опускания (ГЛАВНАЯ ФАЗА для тебя!):**

```
Секунды:  1  -  2  -  3  -  4  -  5
Действие: МЕДЛЕННО опускать → сопротивляться → контроль → растяжение
```

**Техника (ДЛЯ УКРЕПЛЕНИЯ ПРАВОГО КОЛЕНА!):**

- Опускать **ОЧЕНЬ МЕДЛЕННО** (4-5 сек) ← критично!
- **СОПРОТИВЛЯТЬСЯ весу** (негативная фаза)
- **НЕ бросать ноги вниз!**
- **НЕ выпрямлять колени до упора!** (оставить микросгибание)
- Чувствовать растяжение подколенных

### **❌ Типичные ошибки:**

|**Ошибка**|**Почему опасно для тебя**|**Как исправить**|
|---|---|---|
|**Быстрое опускание**|Не укрепляются подколенные!|**МЕДЛЕННО!** 4-5 сек обязательно!|
|Отрыв таза|Работает поясница, не ноги|**ПРИЖАТЬ ТАЗ!** Напрячь пресс|
|Полное выпрямление|Гиперэкстензия правого колена|**МИКРОСГИБАНИЕ!** Не до конца|
|Рывок вверх|Нет контроля|**ПЛАВНО**, думать о подколенных|

### **Что должен чувствовать:**

- ✅ **Сжатие подколенных** вверху
- ✅ **Жжение в подколенных** (особенно при медленном опускании)
- ✅ Работу **икр** (немного)
- ❌ НЕ должно тянуть **под коленом** (если тянет — слишком тяжёлый вес!)

### **💡 Для твоего правого колена:**

**Это упражнение — ТЕРАПИЯ для гиперэкстензии!**

- **Медленный негатив** (4-5 сек) тренирует подколенные **удерживать колено**
- Делай **КАЖДУЮ тренировку ног** (2 раза/неделю)
- Можно добавить **3-й подход** только для правой ноги

### **Прогрессия:**

```
Неделя 1-2:  3×15, 40кг
Неделя 3-4:  3×15, 45кг
Неделя 5-6:  3×15, 50кг
Неделя 7-12: 3×12-15, 55-60кг (НЕ гнаться за весом! Темп важнее!)
```

## **12. ЗАШАГИВАНИЯ НА ПЛАТФОРМУ**

### **Цель:** функциональная сила + контроль коленей + выравнивание

### **ИП:**

```
Платформа 40-50см, гантели в руках:
- Высота платформы: чтобы бедро было параллельно полу при подъёме
- Гантели в руках вдоль тела
- Стоять перед платформой на расстоянии 20-30см
```

**Подготовка:**

1. Взять гантели
2. Встать перед платформой
3. Грудь вперёд, лопатки слегка сведены

### **Фаза подъёма:**

```
Секунды:  1  -  2
Действие: поставить ногу → отталкиваться ПЯТКОЙ → подняться → стоять на платформе
```

**Техника (КОНТРОЛЬ КОЛЕНЕЙ!):**

- Поставить **ВСЮ СТОПУ** на платформу (не только носок!)
- **ОТТОЛКНУТЬСЯ ПЯТКОЙ** (вес на пятке!) ← критично для стоп!
- **КОЛЕНО НАД СТОПОЙ!** (не уходит внутрь!) ← смотри в зеркало!
- Подниматься **СИЛОЙ ПЕРЕДНЕЙ НОГИ** (задняя не помогает!)
- Встать на платформу **НЕ блокируя колено** (микросгибание)

### **Фаза опускания:**

```
Секунды:  1  -  2
Действие: медленно опуститься → контроль → не бросать ногу
```

**Техника:**

- Опускаться **МЕДЛЕННО** (2 сек)
- **Контроль равновесия**
- Та же нога опускается назад
- **Не прыгать вниз!**

### **❌ Типичные ошибки:**

|**Ошибка**|**Почему опасно для тебя**|**Как исправить**|
|---|---|---|
|**Колено внутрь (вальгус)**|Усиливает проблему|**КОНТРОЛЬ!** Колено над стопой!|
|Толчок задней ногой|Не работает передняя, нет смысла|**ПЕРЕДНЕЙ НОГОЙ!** Задняя — только касается|
|Вес на носке|Стопа не работает|**ВЕС НА ПЯТКЕ!** Отталкиваться пяткой|
|Наклон вперёд|Не работают ягодицы|**КОРПУС ВЕРТИКАЛЬНО!**|

### **💡 Для тебя:**

**НАЧИНАЙ СО СЛАБОЙ (левой) НОГИ!**

- 12 раз левой → 12 раз правой
- Тот же вес
- Контроль вальгуса каждый подход

### **Что должен чувствовать:**

- ✅ Работу **ягодицы** при подъёме
- ✅ Работу **квадрицепса** передней ноги
- ✅ Давление в **пятке**
- ❌ НЕ должно болеть в **колене**

### **Прогрессия:**

```
Неделя 1-2:  3×12, без веса (отработка!)
Неделя 3-4:  3×12, 8кг гантели
Неделя 5-6:  3×12, 10кг
Неделя 7-12: 3×12-15, 12-14кг
```

## **13. ПОДЪЁМ НА НОСКИ**

### **Цель:** укрепление икр (важно для стоп + голеностопа)

### **ИП:**

```
Стоя в тренажёре (или со штангой):
- Носки на платформе, пятки висят
- Колени СЛЕГКА СОГНУТЫ (НЕ прямые!) ← для тебя!
- Корпус вертикально
```

**Техника:**

```
Темп 2-1-3:
- 2 сек вверх (подъём на носки)
- 1 сек пауза (сжать икры)
- 3 сек вниз (растяжение)
```

**Фазы:**

1. **Опуститься вниз** → растяжение икр + ахилла (3 сек)
2. **Подняться на носки** → максимально высоко (2 сек)
3. **Пауза вверху** → сжать икры (1 сек)

### **❌ Типичные ошибки:**

|**Ошибка**|**Почему опасно для тебя**|**Как исправить**|
|---|---|---|
|**Прямые колени**|Гиперэкстензия правого!|**СЛЕГКА СОГНУТЬ!** Весь подход|
|Частичная амплитуда|Не работают икры|**ПОЛНАЯ!** Вверх максимально, вниз до растяжения|
