## **1. ПОДТЯГИВАНИЯ ШИРОКИМ ХВАТОМ (ГРАВИТРОН)**

### **Цель:** укрепление широчайших + нижних трапеций (против кифоза)

### **Исходное положение (ИП):**

```
Настройка гравитрона:
- Противовес: начни с 60-70% веса тела (если ты 92кг → 55-65кг противовеса)
- Ступени: встать коленями на платформу (НЕ стопами!)
- Хват: шире плеч на 10-15см, большие пальцы СВЕРХУ грифа (не обезьяний хват!)
```

**Подготовка:**

1. Повиснуть на прямых руках
2. **ОПУСТИТЬ ПЛЕЧИ ВНИЗ** (тянуть от ушей!) ← КРИТИЧНО!
3. **Свести лопатки** (как будто зажимаешь карандаш между ними)
4. Грудь вперёд, взгляд вверх под углом 45°

### **Фаза подъёма (концентрическая):**

```
Секунды:  1  -  2  -  3
Действие: тянуть локтями вниз → к бокам → пауза вверху
          (НЕ руками! Представь, что локти — это крючки)
```

**Техника:**

- Тянуться **ГРУДЬЮ к перекладине** (НЕ подбородком!)
- Локти идут **ВНИЗ-НАЗАД** (не в стороны)
- **Пауза 2 сек вверху** (лопатки максимально сведены)
- Грудина касается перекладины (или почти)

### **Фаза опускания (эксцентрическая):**

```
Секунды:  1  -  2
Действие: медленно опускаться → держать контроль → НЕ бросать вниз
```

**Техника:**

- Опускать **МЕДЛЕННО** (2 сек)
- **НЕ расслаблять лопатки!** (держать сведёнными до конца)
- Внизу руки прямые, но **плечи НЕ уходят к ушам** (держать опущенными)

### **❌ Типичные ошибки (особенно при кифозе!):**

|**Ошибка**|**Почему опасно**|**Как исправить**|
|---|---|---|
|Плечи к ушам|Усиливает кифоз, перегрузка шеи|**ОПУСКАТЬ ПЛЕЧИ!** Думать "плечи в карманы"|
|Тянуть подбородком|Шея вперёд → горб усиливается|Тянуться **грудью**, не лицом|
|Раскачивание|Нет контроля, травма плеч|Корпус стабильный, движение только в плечах|
|Локти вперёд|Не работают широчайшие|Локти **назад**, к спине|

### **Что должен чувствовать:**

- ✅ Напряжение в **широчайших** (под лопатками, по бокам спины)
- ✅ Работу **между лопаток** (нижние трапеции)
- ✅ Лёгкое жжение в **предплечьях**
- ❌ НЕ должно болеть в **шее** или **плечах спереди**

### **Прогрессия:**

```
Неделя 1-2:  4×8, противовес 60кг
Неделя 3-4:  4×10, противовес 55кг
Неделя 5-6:  4×10, противовес 50кг
Неделя 7-8:  4×12, противовес 45кг
Неделя 9-12: 4×12, противовес 40кг
Цель 3 мес:  4×10 без противовеса (чистые подтягивания)
```

## **2. ТЯГА ГАНТЕЛИ В УПОРЕ**

### **Цель:** широчайшие + выравнивание асимметрии (у тебя 45%/55% нагрузка)

### **ИП:**

```
Скамья + гантель:
- Левая нога + левая рука на скамье (упор)
- Правая нога на полу (стопа ПОЛНОСТЬЮ, не носок!)
- Правая рука с гантелью висит вниз
- Спина ПАРАЛЛЕЛЬНА полу (не округлять!)
```

**Настройка:**

1. **Таз НЕ разворачивается** (оба "косточки" таза смотрят в пол)
2. Плечи на одном уровне
3. Шея — продолжение позвоночника (не задирать голову)
4. **Свободная рука упирается в скамью** (не висит!)

### **Фаза подъёма:**

```
Секунды:  1  -  2  -  3
Действие: тянуть гантель → к БЕДРУ (не к груди!) → пауза → локоть назад
```

**Техника:**

- **Тянуть К БЕДРУ** (не к груди, не к плечу!) ← ВАЖНО!
- Локоть **ВДОЛЬ КОРПУСА** (не в сторону)
- **Лопатка к позвоночнику** (тянуть лопаткой, не рукой)
- Пауза 1 сек вверху
- **Таз НЕ крутится!** (самая частая ошибка)

### **Фаза опускания:**

```
Секунды:  1  -  2  -  3
Действие: медленно опускать → контроль → растяжение широчайшей
```

**Техника:**

- Опускать **МЕДЛЕННО** (3 сек)
- Чувствовать **растяжение широчайшей** (под лопаткой)
- Не бросать гантель вниз
- Плечо не уходит вперёд

### **❌ Типичные ошибки:**

|**Ошибка**|**Почему опасно**|**Как исправить**|
|---|---|---|
|Тянуть к груди|Работает бицепс, не спина|К **БЕДРУ!** Представь, что в кармане брюк|
|Таз разворачивается|Не работают нужные мышцы, торсия таза усиливается|**Зафиксировать таз!** Напрячь корпус|
|Рывок вверх|Нет контроля, травма|**Медленно**, думать о лопатке|
|Округление спины|Перегрузка поясницы|Спина **ПРЯМАЯ**, грудь вперёд|

### **Что должен чувствовать:**

- ✅ Работу **широчайшей** (под лопаткой, сбоку спины)
- ✅ Сведение **лопатки** к позвоночнику
- ✅ Растяжение в нижней точке
- ❌ НЕ должно тянуть **бицепс** или **плечо**

### **⚠️ Для тебя (асимметрия 45%/55%):**

**ВСЕГДА начинай со СЛАБОЙ стороны (левой!):**

1. Делаешь 3×12 левой
2. Делаешь 3×12 правой **с тем же весом**
3. Даже если правой легче — **НЕ увеличивай вес!**
4. Цель: выровнять силу, потом прогрессировать

### **Прогрессия:**

```
Неделя 1-2:  3×10, 24кг
Неделя 3-4:  3×12, 24кг
Неделя 5-6:  3×12, 28кг
Неделя 7-8:  3×12, 30кг
Неделя 9-12: 3×12, 32кг
```

## **3. FACE PULL**  https://www.youtube.com/shorts/IeOqdw9WI90

### **Цель:** задние дельты + нижние трапеции (ОТ КИФОЗА — САМОЕ ВАЖНОЕ!)

### **ИП:**

```
Канатная рукоять на верхнем блоке:
- Высота: уровень лица
- Вес: лёгкий! (начни с 15-20кг, не больше)
- Стойка: ноги на ширине плеч, слегка согнуты
- Хват: ладони к себе, за концы каната
```

**Подготовка:**

1. Встать на расстоянии 1.5-2м от блока
2. Руки прямые, канат натянут
3. **Плечи ОПУЩЕНЫ** (не к ушам!)
4. Грудь вперёд

### **Фаза подъёма (самое важное упражнение!):**

```
Секунды:  1  -  2  -  ПАУЗА 2 сек
Действие: тянуть канат → к ушам (не к груди!) → локти ВВЕРХ → пауза
```

**Техника (КРИТИЧНО!):**

- Тянуть канат **К УШАМ** (не к груди, не к подбородку!)
- **Локти ВЫШЕ кистей** ← самое важное! (локти идут вверх-назад)
- **Локти В СТОРОНЫ** (разводить широко, как крылья)
- **Лопатки К ПОЗВОНОЧНИКУ** (максимально свести)
- **ПАУЗА 2 сек** в точке максимального сведения
- Кисти у висков (разорвать канат в стороны)

### **Фаза опускания:**

```
Секунды:  1  -  2
Действие: медленно вернуть → контроль → НЕ расслаблять лопатки
```

**Техника:**

- Опускать **МЕДЛЕННО** (2 сек)
- **Сопротивляться весу** (не бросать)
- Плечи остаются опущенными

### **❌ Типичные ошибки (при кифозе часто!):**

|**Ошибка**|**Почему опасно**|**Как исправить**|
|---|---|---|
|Локти вниз|Работают широчайшие, не задние дельты|**ЛОКТИ ВВЕРХ!** Выше кистей!|
|Тянуть к груди|Не работают нужные мышцы|К **УШАМ!** Представь, что затыкаешь уши локтями|
|Плечи к ушам|Усиливает кифоз|**ОПУСТИТЬ ПЛЕЧИ!** Держать весь подход|
|Слишком тяжёлый вес|Нет контроля, техника ломается|**ЛЁГКИЙ ВЕС!** 15-20кг достаточно|
|Нет паузы|Мышцы не успевают сократиться|**ПАУЗА 2 сек!** Обязательно!|

### **Что должен чувствовать:**

- ✅ **Жжение между лопаток** (это цель!) ← нижние трапеции
- ✅ Работу **задних дельт** (сзади плеч)
- ✅ Сведение лопаток
- ❌ НЕ должно тянуть **бицепс** или **трапеции сверху** (возле шеи)

### **💡 Лайфхак для тебя:**

**Делай Face Pull В НАЧАЛЕ каждой тренировки** (не только в день спины):

- 2-3 подхода × 15-20 повторов
- Лёгкий вес, пауза 2 сек
- **Активирует нужные мышцы перед всеми жимами!**

### **Прогрессия:**

```
Неделя 1-2:  4×15, 15кг
Неделя 3-4:  4×18, 17.5кг
Неделя 5-6:  4×20, 20кг
Неделя 7-12: 4×20, 22.5кг (НЕ гнаться за весом! Техника!)
```

## **4. ТЯГА НИЖНЕГО БЛОКА К ПОЯСУ** https://www.youtube.com/watch?v=hUV6XDtNTLU

### **Цель:** средняя часть спины (ромбовидные + средние трапеции)

### **ИП:**

```
Сидя на скамье, ноги на платформах:
- Хват: узкий (V-рукоять) или параллельный (узкий)
- Стопы на платформах ПОЛНОСТЬЮ
- Колени СЛЕГКА СОГНУТЫ (НЕ прямые!) ← для тебя критично!
- Спина прямая, грудь вперёд
```

**Подготовка:**

1. Вытянуть руки вперёд, взять рукоять
2. **Откинуться назад на 10-15°** (не вертикально!)
3. Грудь вперёд, лопатки слегка сведены
4. **Поясница слегка прогнута** (НЕ округлять!)

### **Фаза подъёма:**

```
Секунды:  1  -  2  -  3  -  ПАУЗА 2 сек
Действие: тянуть рукоять → к низу груди → локти назад → пауза → свести лопатки
```

**Техника:**

- Тянуть **К НИЗУ ГРУДИ** (не к шее, не к животу!)
- **Локти ВДОЛЬ КОРПУСА** (не разводить в стороны)
- **Лопатки МАКСИМАЛЬНО СВЕСТИ** в конечной точке
- **ПАУЗА 2 сек** (обязательно!)
- Корпус НЕ отклоняется назад (только руки двигаются)

### **Фаза опускания:**

```
Секунды:  1  -  2  -  3
Действие: медленно вытягивать руки → НЕ округлять спину → растяжение широчайших
```

**Техника:**

- Опускать **МЕДЛЕННО** (3 сек)
- **Спина ПРЯМАЯ** (самая частая ошибка — округление!)
- Можно слегка подать корпус вперёд (растяжение), но **спина НЕ круглится!**
- Лопатки расходятся, но контролируемо

### **❌ Типичные ошибки:**

|**Ошибка**|**Почему опасно**|**Как исправить**|
|---|---|---|
|Округление спины|Перегрузка поясницы, кифоз усиливается|**ГРУДЬ ВПЕРЁД!** Весь подход держать|
|Отклонение корпусом|Работает поясница, не спина|Корпус **СТАБИЛЬНЫЙ**, движение только в руках|
|Тянуть к животу|Работают широчайшие (их и так достаточно)|К **НИЗУ ГРУДИ!** (уровень солнечного сплетения)|
|Рывок|Нет контроля|**ПЛАВНО**, думать о лопатках|

### **Что должен чувствовать:**

- ✅ Сведение **между лопаток** (ромбовидные)
- ✅ Напряжение **средней части спины**
- ✅ Растяжение в нижней точке
- ❌ НЕ должно болеть в **пояснице**

### **Прогрессия:**

```
Неделя 1-2:  3×12, 55кг
Неделя 3-4:  3×15, 55кг
Неделя 5-6:  3×15, 60кг
Неделя 7-12: 3×15, 65-70кг
```
