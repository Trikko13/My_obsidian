# INBOX vs MOC vs ZETTEL — в чём разница?

## 🎯 Главное правило

| Папка          | Что там            | Когда добавлять               | Как долго живёт        |
| -------------- | ------------------ | ----------------------------- | ---------------------- |
| **00-INBOX/**  | Сырые мысли        | Мгновенно (1 сек)             | 1-3 дня                |
| **20-ZETTEL/** | Обработанные мысли | После обдумывания (вечером)   | Навсегда               |
| **30-MOC/**    | Карты навигации    | Когда есть 5+ заметок по теме | Навсегда (обновляется) |


# 🎯 Краткая памятка по папкам

| Папка | Что | Когда | Срок жизни |
|-------|-----|-------|------------|
| **00-INBOX** | Сырые мысли | Сразу | 1-3 дня |
| **10-SOURCES** | Конспекты книг | После чтения | Навсегда |
| **20-ZETTEL** | Ваши идеи | После обработки | Навсегда |
| **30-MOC** | Карты тем | При 5+ Zettel | Навсегда (обновляется) |
| **40-PROJECTS** | Активные проекты | Проект начат | До завершения |
| **50-DAILY** | Дневник | Каждый день | Навсегда (опционально) |
| **60-ARCHIVE** | Старые проекты | Проект завершён | Навсегда |

✅ Твой workflow (итого)

## Во время чтения:
```
Читаю Дорофеева
↓
Идея → записал в INBOX (своими словами)
↓
Продолжаю читать
```

## Вечером (15 мин):
```
Открыл INBOX
↓
Идея интересная? 
  ДА → создал Zettel (DORO-010)
  НЕТ → удалил
↓
Добавил в MOC-Дорофеев
↓
Очистил INBOX
```

```
