## 🗺️ Структура знаний

### 📚 Фундаментальные концепции

**Базовая модель:**
- **Рациональный тип** (префронтальная кора) — планирует, анализирует
- **Обезьянка** (лимбическая система) — исполняет, но боится сложного
- **Мыслетопливо** — ограниченный ресурс
- **Список задач** - приложуха Tic-Tic
- **Список проектов**  -  приложуха Tic-Tic
- **Инкубатор идей**- на физ носителе cloud.ru и общий буфер в тик-тик 
- **Список справочной  информации** - в целом я считаю в Obsidian можно вести подобный  

**Ключевая идея:**
> Задача рационального типа — выдать обезьянке правильные указания, понятные **ей**, а не самому себе. Сперва думать ,формулируя первоочередное действие для каждой задачи - чтобы потом не тратить энергию на переделки.

## 📝 Заметки

### Ключевые инсайты из первых 100 страниц:

1. **Обезьянка боится сложного** → формулируй задачи максимально просто
2. **План устаревает** → не планируй весь проект, только 1-2 задачи
3. **Мыслетопливо ограничено** → экономь на мелочах, трать на важное
4. **Голова — не хранилище** → всё во внешнюю систему
5. **20 минут лучше нуля** → метод феи работает
